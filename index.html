لغات برمجة الويب

اكتشف التقنيات الأساسية لبناء مواقع وتطبيقات الويب الحديثة

HTML5 هيكل

هي لغة الترميز الأساسية المستخدمة لإنشاء هيكل صفحات الويب ومحتواها. لا يمكن بناء موقع بدونها.

Frontend

CSS3 تنسيق

تستخدم لتصميم وتنسيق صفحات الويب، والتحكم في الألوان والخطوط والتخطيط (Layout) والتجاوب مع الشاشات.

Frontend

JavaScript تفاعلية

لغة البرمجة التي تجعل الصفحات تفاعلية وحية. تعمل في المتصفح وأيضاً في الخادم عبر بيئة Node.js.

Frontend & Backend

Python منطق

لغة قوية وسهلة التعلم، تستخدم في الويب عبر أطر عمل شهيرة مثل Django و Flask للتعامل مع البيانات والخوادم.

Backend

PHP سكربت

لغة مصممة خصيصاً للويب، تشغل جزءاً كبيراً من الإنترنت (بما في ذلك ووردبريس). ممتازة للتعامل مع قواعد البيانات.

Backend

SQL بيانات

ليست لغة برمجة تقليدية، بل لغة استعلام تستخدم للتواصل مع قواعد البيانات وتخزين واسترجاع المعلومات.
